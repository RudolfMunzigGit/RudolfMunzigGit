# Munzig’s

**Lottery data & tools**

I’m building **Munzig’s** — a multilingual project focused on verified lottery data, historical results and practical tools for working with lottery information.

## Current focus

- verified lottery datasets and draw histories
- multilingual lottery interfaces
- data validation and provenance
- statistics, history and result-checking tools
- responsive web and PWA development
- privacy-conscious client/server architecture

## Project principles

- verified data before presentation
- clear separation of public and protected data
- native-quality localization
- clean, precise and mobile-friendly design
- no ticket sales or gambling operator affiliation
